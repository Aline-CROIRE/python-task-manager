# Sprint 1 Plan

## Sprint Goal

Deliver the first usable version of the Python Personal Task Manager, allowing users to add tasks and view their task list.

## Selected Product Backlog Items

| ID | User Story | Estimate |
|---|---|---:|
| US1 | Add a Task | 2 story points |
| US2 | View Tasks | 1 story point |
| **Total** | | **3 story points** |

## Sprint Scope

### Included
- Create the initial Python application structure.
- Allow users to add tasks.
- Display the task list.
- Reject empty task descriptions.
- Add automated tests for the implemented behavior.
- Configure a GitHub Actions workflow to run the tests.

### Not Included
- Marking tasks as complete.
- Deleting tasks.
- Saving tasks between application sessions.
- Advanced monitoring or logging.

These features will be considered in later work.

## Tasks and Responsibilities

As a solo learner, I will perform all project roles and activities.

1. Create the application entry point and task-management logic.
2. Implement task creation and task listing.
3. Handle empty input.
4. Write and run automated tests.
5. Configure continuous integration with GitHub Actions.
6. Review the results and document lessons learned.

## Sprint Acceptance Conditions

Sprint 1 is successful when:

- Users can add valid tasks.
- Users can view tasks.
- Empty task descriptions are rejected.
- Automated tests pass.
- GitHub Actions runs the tests automatically when changes are pushed.
- The completed work is committed and pushed to GitHub.

## Sprint Review Plan

Demonstrate adding tasks, displaying them, and handling empty input. Show the automated test results and CI workflow.

## Sprint Retrospective Plan

After the review, identify what went well, what was difficult, and at least two improvements to apply in Sprint 2.
