# Python Personal Task Manager

## 1. Product Vision

To build a simple, reliable Python command-line application that helps users organize their daily activities by creating, viewing, completing, and deleting tasks.

The application will demonstrate how Agile planning and DevOps practices can be applied to a small software project through incremental development, automated testing, and continuous integration.

## 2. Target Users

People who want a lightweight way to manage everyday tasks without needing a complex application or an internet connection.

## 3. Product Goals

- Allow users to manage tasks through a simple command-line menu.
- Validate user input and handle errors gracefully.
- Maintain readable, modular, and testable Python code.
- Use Git and GitHub to track incremental development.
- Automate tests using a continuous integration pipeline.
- Demonstrate iterative improvement across two sprints.
